# IELTS Speaking Lab

固定网站：https://liu-wanling0306.github.io/ielts_speaking/
唯一正式仓库：https://github.com/Liu-Wanling0306/ielts_speaking
当前版本：**1.5.0**

个人口语训练网站；Band 7.5是目标，不是官方评分。已依据本轮上传的73页预测PDF逐题核对；预测来源与校订方法见网页“预测覆盖核查”。训练补充题与预测原题分别标注。

## 学习结构

- Part 1：PDF 24话题105问；另保留14道旧拓展题，共119问。23条原始不同回答保留，13条完全重复项合并。
- Part 2：13个母素材单元，保留29道原文件题，补齐2道PDF漏题，并保留8道明确标注的迁移题，共39题。母素材 → 搭配回忆 → 口头复述 → 换题迁移。
- Part 3：PDF 26组129问；另保留33道旧拓展题，共162问，37条原回答均保留。
- 四色标注：故事线索、搭配、时态线索、第三人称单数；标注只提示部分明确结构。
- 草稿、搭配答案、进度、复习标记和个人错误保存在浏览器localStorage；通过JSON导出和导入跨设备搬运，不自动云同步。
- 计时仅计时，不录音、不识别语音、不自动打分。

## 本地预览与检查

```bash
python3 -m http.server 8001 --bind 127.0.0.1
```

打开 http://127.0.0.1:8001 ，不要直接双击HTML，因为浏览器会限制加载JSON。

```bash
python3 check.py
node --check app.js
python3 tests/verify_ui.py
```

浏览器测试需要安装Playwright及Chromium。可用`SPEAKING_TEST_URL`指定测试地址。

## 更新发布

1. 检查Git状态，保护未提交改动，再`git pull --ff-only`。
2. 沿用稳定内容ID和`ieltsSpeaking:user:v1`存储键；不得重编号已有题目。
3. 新增内容标注来源；原文与改写分开，不虚构个人经历。
4. 同步`library.json`、`releases.json`、页面资源版本参数、README和CHANGELOG。
5. 运行相关检查和浏览器测试，确认旧草稿可恢复。
6. 审查差异，提交，推送`main`；重要发布建立对应Git标签。
7. 等待GitHub Pages构建成功，并打开网站核验本次提交、版本与功能。

GitHub Pages发布来源：`main`分支根目录。不要将令牌或其他凭据写入仓库。

## 1.4.0 考试模拟

- 官方流程依据：https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-speaking ，核查日期2026-11-19。正式Part 1为4–5分钟，Part 2含1分钟准备和最多2分钟陈述及1–2道收尾追问，总计3–4分钟；Part 3关联Part 2，4–5分钟。题量由时间和考官追问决定，不是官方固定问数。
- 本模块Part 1选择背景题组及两组日常话题，共10–12问；Part 2一张题卡及两道个人化收尾追问；Part 3在配置的关联范围抽4–6问。默认本段上限4分30秒，常规计时约12–13分钟；手动提前结束会缩短总时长，暂停不计入作答时间。
- `mock-core.js` 负责去重、优先级、组卷和备份数据校验；`mock-exam.js` 负责倒计时、自动切题、暂停续练和复盘。`library.mock_exam` 保存规则及每张题卡的Part 3关联题组。
- 优先级为：从未练习/明确不熟悉/主动待复习 → 需巩固或已练但未自评 → 熟练。同档随机，并优先选择关联Part 3新题比例更高的题卡与新题比例更高的Part 1话题。相同问句或完全相同参考答案的重复题合并，进度同时更新别名ID。关联Part 3题及Part 1常见背景题可能因组卷限制重复。
- 仅在答完或计时结束时记录尝试；组卷、准备、暂停、跳过及未展示题不标为已练。完整模拟或提前结束后逐题自评；不熟悉题立即回到优先池。
- 模拟状态保存在同一`ieltsSpeaking:user:v1`键下的`mock`字段，包含熟练度、最近50轮历史和可续练场次。原JSON备份会同时导出；旧备份没有此字段时不覆盖模拟记录。
- 离开模块、切后台或刷新前自动暂停；重新载入保留当前题和剩余时长。客户端计时不代替官方考官，模块不录音、不识别语音、不自动打分。题卡收尾追问为明确标注的训练补充。

模拟回归检查：`node tests/verify_mock_core.js` 及 `SPEAKING_TEST_URL=http://127.0.0.1:8001 python3 tests/verify_mock_ui.py`。


## 1.4.1 全题库可抽取检查

组卷使用合并后的同主题Part 1题组，原有拓展题共同参与抽取；Part 3关联表包含对应原有拓展题组。回归检查覆盖所有可用题的可达性，避免题池计数包含无法抽到的题。


## 1.5.0 整Part展示与英文听题

当前模拟一次显示整个Part的所有题目，逐题手动开始/完成，再手动进入下一Part。倒计时到零只提示，不跳转、不自动记练习完成。Part 2准备、陈述和两道收尾追问同屏，均需手动确认。

每次开始新题先使用浏览器SpeechSynthesis朗读英文（优先en-GB，其次其他英文语音）；朗读结束才启动答题倒计时。支持重听、停止、语音出错或不支持时显式手动计时。后台、导航、刷新会取消当前朗读并暂停计时，旧朗读回调不能启动其他题目的计时。读题不占答题时间，实际总时长由用户手动确认决定。

模拟schema仍为1；新增可选的逐步骤完成状态与听题标记，读取旧进行中场次时按已完成结果迁移，不重新抽题或丢失熟练度。
