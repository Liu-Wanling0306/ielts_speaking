# Project instructions

This is the independent personal speaking site. Canonical repository: https://github.com/Liu-Wanling0306/ielts_speaking . Publish main at repository root via GitHub Pages.

- Never modify the separate IELTS writing repository for speaking updates.
- Preserve existing IDs and the localStorage key `ieltsSpeaking:user:v1`; preserve backup compatibility.
- Keep `source/original-upload.html` unchanged. Original answers live in `answer`; edits/additions belong in `reference` with provenance notes.
- Cue bullets and newly generated prompts are teaching additions unless original source evidence is supplied. Do not invent personal experiences or official exam verification.
- Keep version metadata, resource query versions, releases.json, README and CHANGELOG consistent.
- Run `python3 check.py`, `node --check app.js`, and relevant browser tests before publication.
- Do not commit credentials, temporary screenshots or personal browser backups.
- After pushing, verify the exact commit is deployed and check the live URL before claiming publication.
